07 ECoding

Naše produkty.

01

Scanverion

Z obrázka dokumentu k dátam, ktoré vaša aplikácia vie použiť. API od ECoding pre tímy, ktoré spracúvajú dokumenty a obrázky. Vytiahne polia, nájde objekty a skontroluje kvalitu obrazu bez samostatných integrácií.

  • Polia dokumentu a MRZ.
  • Dokumenty, tváre a čiarové kódy.
  • Kontrola rozmazania a otočenia.

Navštíviť Scanverion · O produkte

  "results": {

  }
}

Dokumentová inteligencia
